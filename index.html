Your first program

Every Java program lives inside a class, and every runnable class needs a main method.

HelloWorld.java

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, freshmen!");
        System.out.println("Welcome to Java.");
    }
}

Compile and run

javac HelloWorld.java
java HelloWorld
Two rules to remember

1. The file name must match the public class name exactly — HelloWorld.java holds public class HelloWorld.

2. Java is case-sensitive. main is not Main, and System is not system.

Variables & data types

Java is statically typed — every variable declares its type up front, and that type never changes.

Type Holds Example
int Whole numbers int age = 18;
double Decimal numbers double gpa = 3.75;
char One character — single quotes char section = 'A';
boolean true or false boolean enrolled = true;
String Text — double quotes (an object, not a primitive) String name = "Maria"; 
public class Variables {
    public static void main(String[] args) {
        int age = 18;
        double gpa = 3.75;
        char section = 'A';
        boolean enrolled = true;
        String name = "Maria";

        // Joining text with + is called concatenation
        System.out.println(name + " is " + age + " years old.");
        System.out.println("Enrolled? " + enrolled);

        // printf lets you format the output
        System.out.printf("%s - GPA %.2f - section %c%n", name, gpa, section);

        // final means the value can never be reassigned
        final double PI = 3.14159;
        System.out.println("PI = " + PI);
    }
}

Arithmetic & the integer division trap

Operators behave differently depending on the types on either side. This is the single most common bug in a first Java program. 

public class Operators {
    public static void main(String[] args) {
        int a = 7, b = 2;

        System.out.println(a + b);   // 9
        System.out.println(a - b);   // 5
        System.out.println(a * b);   // 14
        System.out.println(a / b);   // 3    <- integer division!
        System.out.println(a % b);   // 1    <- the remainder

        // Cast one operand to double to get a decimal result
        System.out.println((double) a / b);   // 3.5

        // Shorthand assignments
        int count = 0;
        count++;      // count = count + 1
        count += 5;   // count = count + 5
        System.out.println(count);            // 6
    }
}
The trap

7 / 2 is 3, not 3.5. When both operands are int, Java throws away the decimal part. Cast one side to double first — (double) a / b — and you get 3.5.

Reading input with Scanner

Scanner reads what the user types in the console. Import it from java.util at the top of the file. 

import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Your name: ");
        String name = sc.nextLine();   // reads a whole line of text

        System.out.print("Your age: ");
        int age = sc.nextInt();        // reads one integer

        System.out.println("Hi " + name + ", next year you'll be " + (age + 1) + ".");

        sc.close();                    // good habit: release the resource
    }
}
Method Reads
sc.nextLine() A full line of text, including spaces
sc.next() A single word — stops at the first space
sc.nextInt() One whole number
sc.nextDouble() One decimal number
The newline gotcha

nextInt() leaves the Enter key sitting in the input buffer. If you call nextLine() right after it, you'll get an empty string. Fix it with one extra sc.nextLine(); to swallow the leftover newline.

Decisions: if / else and switch

Java evaluates a condition that must produce a boolean, then runs the matching block. Only the first true branch runs. 

public class Decisions {
    public static void main(String[] args) {
        int score = 82;

        if (score >= 90) {
            System.out.println("A");
        } else if (score >= 80) {
            System.out.println("B");
        } else if (score >= 70) {
            System.out.println("C");
        } else {
            System.out.println("Needs improvement");
        }

        // switch is cleaner when you compare one value against fixed cases
        // (arrow syntax requires Java 14 or newer)
        int day = 3;
        switch (day) {
            case 1, 2, 3, 4, 5 -> System.out.println("Weekday");
            case 6, 7          -> System.out.println("Weekend");
            default            -> System.out.println("Not a day");
        }

        // Comparison:  ==  !=  <  <=  >  >=
        // Logic:       &&  (and)   ||  (or)   !  (not)
        boolean passing = score >= 75 && score <= 100;
        System.out.println("Passing? " + passing);
    }
}
Order matters

Check the strictest condition first. If you tested score >= 70 before score >= 90, a score of 95 would match the wrong branch.

Loops: for, while and for-each

Pick the loop that matches your situation — counting, waiting for a condition, or walking through a collection. 

public class Loops {
    public static void main(String[] args) {

        // for — use when you know how many times to repeat
        for (int i = 1; i <= 5; i++) {
            System.out.print(i + " ");
        }
        System.out.println();          // prints: 1 2 3 4 5

        // while — use when you loop until a condition changes
        int n = 5, sum = 0;
        while (n > 0) {
            sum += n;
            n--;
        }
        System.out.println("Sum of 1..5 = " + sum);   // 15

        // for-each — use to visit every element of an array
        String[] fruits = {"apple", "banana", "mango"};
        for (String fruit : fruits) {
            System.out.println(fruit);
        }

        // do-while checks its condition after running once
        int tries = 0;
        do {
            tries++;
        } while (tries < 1);

        // break exits the loop early, continue skips to the next round
        for (int i = 1; i <= 10; i++) {
            if (i == 4) continue;   // skip 4
            if (i == 7) break;      // stop at 7
            System.out.print(i + " ");
        }
        System.out.println();       // prints: 1 2 3 5 6
    }
}
Loop Use it when…
for You know the number of repetitions up front
while You repeat until a condition becomes false
for-each You need every element of an array or list
do-while The body must run at least once

Solution walkthrough

Compare this with what you wrote. The important line is the average — note the 3.0, not 3. 

import java.util.Scanner;

public class GradeReport {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Student name: ");
        String name = sc.nextLine();

        System.out.print("Quiz 1: ");
        int q1 = sc.nextInt();
        System.out.print("Quiz 2: ");
        int q2 = sc.nextInt();
        System.out.print("Quiz 3: ");
        int q3 = sc.nextInt();

        // 3.0 forces floating-point division
        double average = (q1 + q2 + q3) / 3.0;

        String grade;
        if (average >= 90)      grade = "A";
        else if (average >= 80) grade = "B";
        else if (average >= 70) grade = "C";
        else if (average >= 60) grade = "D";
        else                    grade = "F";

        int highest = Math.max(q1, Math.max(q2, q3));

        System.out.println("============================");
        System.out.printf(" Student : %s%n", name);
        System.out.printf(" Scores  : %d, %d, %d%n", q1, q2, q3);
        System.out.printf(" Average : %.2f%n", average);
        System.out.printf(" Highest : %d%n", highest);
        System.out.printf(" Grade   : %s%n", grade);
        System.out.println("============================");

        sc.close();
    }
}
Why it works
  • (q1 + q2 + q3) is an int, but dividing by 3.0 promotes it to double.
  • The if / else if chain is ordered from strictest to loosest, so no branch is unreachable.
  • Math.max nests to compare three values at once.
  • %.2f in printf rounds the average to two decimals.
